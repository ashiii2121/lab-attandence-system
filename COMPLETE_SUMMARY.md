### **For Development:**
```bash
# Clone repository
git clone https://github.com/ashiii2121/lab-attandence-system.git
cd lab-attandence-system

# Setup server
cd server
npm install
cp .env.example .env
# Edit .env with your values
npm start

# Setup client (new terminal)
cd client
npm install
npm run dev

# Visit http://localhost:5173
```
